============================================================
NAAMMALA — HOW TO RUN THIS PROJECT (FROM ZIP DOWNLOAD)
============================================================

This file explains every step, starting from the moment you
download the project ZIP, to having the app running on your
own computer.


------------------------------------------------------------
STEP 0 — THINGS YOU NEED INSTALLED FIRST (ONE TIME ONLY)
------------------------------------------------------------

1. Node.js (version 18 or higher)
   Download: https://nodejs.org
   Check it's installed by opening a terminal and typing:
       node -v

2. VS Code (or any code editor)
   Download: https://code.visualstudio.com

3. Git (only needed if you plan to push to GitHub later)
   Download: https://git-scm.com


------------------------------------------------------------
STEP 1 — EXTRACT THE ZIP FILE
------------------------------------------------------------

1. Find the downloaded ZIP file (usually in your Downloads
   folder).
2. Right-click it and choose "Extract All" (Windows) or
   double-click it (Mac).
3. Move the extracted "naammala" folder to wherever you keep
   your projects, e.g. Documents\Projects\naammala


------------------------------------------------------------
STEP 2 — OPEN THE PROJECT IN VS CODE
------------------------------------------------------------

1. Open VS Code.
2. File > Open Folder.
3. Select the "naammala" folder (it should contain a
   "backend" folder and a "frontend" folder inside it).


------------------------------------------------------------
STEP 3 — SET UP A DATABASE (POSTGRES)
------------------------------------------------------------

This app needs a Postgres database to store users, settings,
and jaap counts. The free option used for this project is
Neon, created through Vercel.

1. Go to https://vercel.com and sign in (use "Continue with
   GitHub" for the easiest setup).
2. In the Vercel dashboard, click the "Storage" tab.
3. Click "Create Database" (or find it in the marketplace
   list) and choose "Neon" (Serverless Postgres).
4. Give it a name (e.g. naammala-db), pick a region, and
   create it.
5. Open the Neon project (or go to
   https://console.neon.tech and sign in with the same
   account).
6. Click "Connect" near the top of the Neon dashboard.
7. Copy the full connection string shown there. It looks
   like:
       postgresql://username:password@ep-xxxx.aws.neon.tech/neondb?sslmode=require

   Keep this private — treat it like a password.


------------------------------------------------------------
STEP 4 — SET UP THE BACKEND
------------------------------------------------------------

1. In VS Code, open a terminal: Terminal > New Terminal
2. Run:
       cd backend
       npm install

3. Create a new file inside the "backend" folder named
   exactly:  .env
   (In VS Code: right-click the backend folder in the
   sidebar > New File > type ".env" > Enter)

4. Open the .env file and add these two lines:
       POSTGRES_URL=paste_your_connection_string_here
       GROQ_API_KEY=

   (Leave GROQ_API_KEY empty unless you have a Groq key —
   see Step 7 below.)

5. Save the file.

   IMPORTANT: Never upload or share your .env file — it
   contains secrets.


------------------------------------------------------------
STEP 5 — SET UP THE FRONTEND
------------------------------------------------------------

1. Open a SECOND, separate terminal in VS Code (click the
   "+" icon next to the terminal tabs).
2. Run:
       cd frontend
       npm install

No .env is needed on the frontend.


------------------------------------------------------------
STEP 6 — RUN THE APP
------------------------------------------------------------

You need BOTH the backend and frontend running at the same
time, each in its own terminal.

TERMINAL 1 (backend):
    cd backend
    node server.js

You should see:
    NaamMala backend running on http://localhost:4000

Leave this terminal open.

TERMINAL 2 (frontend):
    cd frontend
    npm run dev

You'll see a link like:
    Local:   http://localhost:5173/

Open that link in your browser (Ctrl+Click it, or paste it
into your browser bar).

You should now see the NaamMala login screen. Create an
account (any name without spaces + a password), go to
Settings to choose the name you want to chant, then use the
Writing Pad to start counting.

To stop either server, click into its terminal and press
Ctrl+C.


------------------------------------------------------------
STEP 7 — OPTIONAL: AI QUOTES WITH GROQ
------------------------------------------------------------

The Dashboard shows a short daily reflection. Without a Groq
key, it rotates between a few calm built-in lines. To get
real AI-generated, ever-changing quotes:

1. Go to https://console.groq.com and sign up (free).
2. Create an API key.
3. Open backend/.env and set:
       GROQ_API_KEY=your_key_here
4. Restart the backend (Ctrl+C, then "node server.js" again).


------------------------------------------------------------
COMMON PROBLEMS
------------------------------------------------------------

"ECONNREFUSED" or "connect ECONNREFUSED 127.0.0.1:5432"
  -> POSTGRES_URL is missing or wrong in backend/.env.
     Double-check you pasted the full Neon connection string.

"{"error":"Route not found"}" at http://localhost:4000
  -> This is normal. The backend only responds to /api/...
     paths. Try http://localhost:4000/api/health instead.

"Cannot find package 'xyz'"
  -> Run "npm install" again inside the backend (or frontend)
     folder — a dependency wasn't installed.

Frontend loads but nothing works
  -> Make sure the backend terminal is still running.

.env file won't save correctly on Windows
  -> Create and edit it directly inside VS Code instead of
     File Explorer (Explorer sometimes renames it to
     ".env.txt").
